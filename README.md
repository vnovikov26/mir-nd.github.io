# Мир Недвижимости Дмитров — сайт агентства

Одностраничный сайт бутик-агентства недвижимости **Ирины Скляровой** (г. Дмитров, Московская область).

## Что умеет сайт

- Презентация агентства, команды и наград
- Интерактивный выбор сценария сделки (переезд, ипотека, маткапитал, удалённая сделка и др.)
- Форма записи на консультацию с лимитом слотов (3 записи на окно)
- Форма заявки с отправкой на email через FormSubmit.co
- Модальное окно политики конфиденциальности (152-ФЗ)
- Адаптивная вёрстка: мобильная панель с кнопками «Позвонить» и «WhatsApp»
- Блок «Дмитров — не дальняя область, а решение» со статистикой рынка
- FAQ через нативный `<details>/<summary>`

## Технологии

| Что | Как |
|-----|-----|
| Вёрстка | Чистый HTML5 / CSS3, без фреймворков |
| Шрифты | Google Fonts: Lora + Nunito Sans |
| Форма | [FormSubmit.co](https://formsubmit.co) (AJAX, без backend) |
| Слоты | Лимит 3 записи на окно, счётчик в `localStorage` |
| SEO | Open Graph, Twitter Card, Schema.org `RealEstateAgent` (JSON-LD) |

## Быстрый старт

Просто откройте файл в браузере:

```bash
open gemini-code-1789133318128.html
```

Или задеплойте на любой статический хостинг (Netlify, GitHub Pages, Яндекс Облако и т.д.) — никакого сервера не нужно.

## Настройка форм

Формы отправляют данные через FormSubmit.co на адрес `info@mir-nd.ru`.  
**При первой отправке FormSubmit пришлёт письмо с подтверждением** — его нужно подтвердить один раз.

Если нужен другой email — найдите в скрипте строки:

```
https://formsubmit.co/ajax/info@mir-nd.ru
```

и замените адрес на нужный.
